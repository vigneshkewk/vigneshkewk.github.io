Featured Work

Foley's Procurement Optimisation Platform

End-to-end procurement analytics for a live NZ business

Nov 2025 – Feb 2026 · Foley's, Christchurch NZ

Built and shipped a full procurement analytics platform for Foley's, a New Zealand plumbing supplies company — integrated directly with their live Accredo ERP system via a secure OAuth 2 connection. The goal: find the cheapest available supplier for every product, catch pricing errors before they cost money, and surface savings opportunities automatically.

  1. Engineered a custom attribute-extraction engine using 80+ regex patterns to parse sizes, materials, thread types, and electrical specs out of unstructured plumbing product descriptions.
  2. Built a tiered TF-IDF duplicate-detection system to catch the same product listed differently across suppliers, with automated master-product selection.
  3. Developed a multi-phase supplier-matching pipeline — vendor code lookup, TF-IDF cosine similarity, direct and fallback code matching — to find the cheapest available supplier for every product.
  4. Built an automated invoice-verification system that flags pricing discrepancies against supplier price books using configurable tolerance thresholds.
  5. Designed an AI-powered supplier recommendation engine that scores and prioritises suppliers by savings, volume, and match quality (Critical / High / Medium / Low).
  6. Built market-pricing tools to benchmark Foley's pricing against the wider supplier market and surface high-margin products.
